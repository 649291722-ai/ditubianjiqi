使用说明（点右上角 i 可关闭）

splmofan · 使用说明
《蛙鸣庭院》单文件地图规划器。纯前端、不联网，数据只存本机浏览器。顶部画布；下方依次：工具栏 / 选项栏 / 图层栏 / 层上限 / 物件 / 素材 / 动态 / 阴影 / 存档 / 导入导出。
绘制工具
笔：点或拖就画；细/中/粗 = 1x1 / 2x2 / 3x3 快捷笔刷，右侧「画笔格」可自定义 NxN（1-32）。
擦：清该格（底图回草地；叠加清该格）。
填充：点一格，相连同种格整片刷成当前素材。
吸色：取图上某格为当前素材。
移动：拖动画布（平移）。
升/降：高度标记 +1 / -1（范围 -64~+64，0=平面；仅标记，不参与阻挡）。
清除当前内容：整张图清回默认（含阴影）。
图层（4 层）
底图：地形底瓦片（每格 1 张）。
地形叠加：地形叠地形（如土地+石路），多层。
贴花：树/花/装饰，多层。
高度标记：-64~+64，负数=下陷（仅标记）。
立体起伏：实体高度层（正=抬升、负=下沉），每格一个高度值、按主格粒度，高差处自动补立面（侧壁）。
显隐：底显 / 地形显 / 贴花显。
渲染顺序：底图→地形叠加→阴影→贴花→立面→高度标记→等高线→阻挡→网格。
立体起伏
每级像素：1 级 = 几像素的显示换算（数据存“级”，此值决定看着多高）。
立面：相邻格有高差时自动补侧壁；侧壁可选自动渐变或自己的素材。
边距：画布四周预留空白，让最外排贴图可探出地图边界。
阻挡：阻挡跟着“画了起伏的格子”走，看不看得见被盖住不算。
本版无子格细分：高度一律按主格，一格一个值。
高度标记与等高线
升降：一次一层，-64~+64。
等高线：在网格之前画高度边界线（颜色随高度渐变）；除“全览”档外都显示高度数字。
格子数 / 格尺寸
格子数 [M]x[N]：地图有多少格（如 64x64）。
格尺寸 [W]x[H]：每格多大像素（默认 24x24；可 70x30、50x34…）。两者独立。
物件（占格 + 阻挡）
占格 [W]x[H] [设为当前素材]：该素材跨几格。
阻挡 [按像素/按格子] [w]x[h] [设为当前素材]：碰撞/阻拦区；按像素=居中按图大小，按格子=从格左上角按格数；默认 1x1。
显示阻挡：像等高线一样叠画阻框，不与其他功能互斥。阻挡会随导出 JSON(framesMeta.b) 给出。
框选 / 随机 / 随机池 / 翻X
框选：点两个素材格圈一块，回图上点一下盖上去。
随机：每画一格从候选里随机取。
随机池：点开后点素材=加入/移出池（蓝框）；优先级：池非空→只用池内；否则框选内；再否则全部。
翻X：画下去的素材左右镜像。
层上限
地形叠加与贴花各自的最大叠层数（1-64）。
素材与导入
导入前先选两件事：类型（地图瓦片/素材贴图/动态素材）与放置方式（填充格子/等比放入）。
等比放入=按原图比例缩放居中（不变形）；填充格子=拉满格内。
导入的 PNG 存本机浏览器，刷新不丢；素材栏名带 [瓦]/[贴] 前缀。
动态（素材/播放/存档）
动态素材：导入时选“动态素材”则进独立列表（不占主素材栏），在“动态”栏可选；用“贴花/地形叠加”层来放。
参数：帧动画（帧数/帧速）或滚动（方向/速度）；可循环。
▶播放：在编辑器里预览动效（只读，默认关）。
动态存档：新建/保存/读取/删除/从记录导入；记录框显示选中存档的 JSON。
记录框：每点“设为当前素材”追加一行。
阴影
独立一层。形状：圆/椭圆/矩形/圆角/方向/自定义（自定义画格：格数 4-64，展开时横向铺满）。
占地 WxH（最多 64）、偏移 X/Y、透明度、重叠加深（不勾=融合/勾=加深）、全局默认。
同一格可叠多张（最多 64）。
放入阴影 / 消除阴影 两个按钮；消除按覆盖区域判定，点阴影覆盖的任一格即可删。
层级：阴影只压地形，不压贴花。
存档 / 导入导出
存档栏：命名保存/读取/删除（存本机）；另设 🔍 存档自检（查看存档体积 / 坏档数 / 字节明细 Top6，用于排查丢档）。
导入导出：导入我的素材 / 导出参考图 / 复制数据 / 导入数据 / 导出文件 / 导入文件。
导出 JSON 含：网格 w/h、格尺寸 cw/ch、四层数据、anims(动态)、framesMeta(名字/类型/占格/阻挡)。
视图栏 / 缩放
撤销（可连撤 40 步）／网格（每格细线 + 每 8 格加粗）／等高线开关／缩放 － ＋（档位 0.25~6，超大图会自动压顶防白块）／适配屏幕。
移动工具 = 拖动画布平移（放大后可平移查看）。
