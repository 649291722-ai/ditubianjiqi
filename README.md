**我们的网页**手机上就能用的像素地图规划器。不用注册、不用下载，`ditubianjiqi.synsbdq.com` 点开直接画。24×24 正方格，四层渲染（底图 / 地形叠加 / 阴影 / 贴花），阴影能单独画，动态素材能播放预览，画完一键导出 JSON，丢进游戏引擎就能读。纯前端、零成本。由凡与 AI（斯帕罗 / 默共同搭建。**参考仓库** `blurymind/tilemap-editor`——一个开源的网页版瓦片地图编辑器，作者 blurymind，MIT 协议，免费随便用。它是我做工具时的参考对象，思路很值得看：浏览器里直接铺图块、导出给游戏引擎吃。我只借鉴了功能思路没搬一行源码，页脚还留着它的链接致敬。喜欢折腾像素游戏的可以去 GitHub 搜这个仓库，纯前端打开就能玩。
