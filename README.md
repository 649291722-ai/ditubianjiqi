# 蛙鸣庭院 · 像素地图规划器

> 在线使用：https://ditubianjiqi.synsbdq.com/
> 打开即用，无需注册、无需下载，手机端友好。

## 这是什么

手机上就能用的像素地图规划器。不用注册、不用下载，点开链接直接画。
画完一键导出 JSON，丢进游戏引擎（如 Phaser）就能读。纯前端、零成本。

## 功能

- **24×24 正方形网格**标准（1:1 原画铺设，防模糊）
- **四层渲染**：底图 / 地形叠加 / 阴影 / 贴花
- **独立阴影层**：基础形状 + 自定义手绘网格、重叠加深、单格多层叠加
- **动态素材**：独立列表、单独导入与存档、循环 / 滚动播放预览
- **素材导入**：「等比放入」/「填充格子」双模式，避免被压扁
- **多格框选、随机取帧（可指定随机池）、跨格大尺寸物件、X 轴镜像**
- **图层独立显隐与透明度滑杆**，宽高独立设置地图格数
- **导出 JSON**：含 `w / h / cw / ch` 与 `framesMeta` 的 `b` 字段（物件占地与碰撞阻挡，供游戏引擎直接判定）
- **版本破缓存机制**：HTML 入口不缓存，静态资源追加 `?v=VER`
